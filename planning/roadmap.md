# Roadmap — Pague Dez

## MVP (v0.1) — em andamento
- [x] Login/cadastro com JWT (só o email do dono vira ADMIN)
- [x] Admin: cadastrar, ativar/desativar, promover usuários
- [x] Registro de flexões com botão PAGUEI!
- [x] Recordes diário, semanal, mensal e anual
- [x] Comemoração com confetes + taça progressiva (Bronze → Lendária)
- [x] Taça "Recruta" no primeiro registro
- [x] Histórico: recordes atuais, galeria de taças, últimas séries
- [x] Gráfico dos últimos 30 dias com linha de recorde
- [x] Tema azul/rosa por sexo
- [x] Identidade visual (estilo slush.app — ver context/design.md)
- [ ] Deploy na Vercel

> **Estratégia (2026-10-06):** usar o básico por 1–2 meses antes de abrir ao público.
> As fases P1/P2 são ideias guardadas — só começam quando o usuário decidir.

## P1 — Hábito e viralização (futuro)
- Desafio "Pague Dez": mandar um amigo pagar dez via link do WhatsApp
- Ofensiva (dias seguidos pagando)
- Card compartilhável da taça (Instagram/WhatsApp)
- PWA instalável + lembrete diário
- Patentes por volume acumulado (Recruta → Soldado → Cabo → Sargento → … → General)

## P2 — Comunidade e receita (futuro)
- Pelotões (grupos) com ranking
- Outros exercícios (abdominal, barra, agachamento, prancha)
- Plano "Oficial" (freemium) e treinos para TAF
